---
name: Revisión de placeholders visuales
description: Criterio para seleccionar y revisar imágenes temporales usadas en interfaces públicas.
---

Las imágenes temporales deben ser distintas entre sí, coherentes con el contenido visual de cada tarjeta y revisarse a tamaño completo antes de presentar la interfaz. Se deben retirar o sustituir las que muestren logotipos, marcas de productos o una relación visual engañosa con el contenido.

**Why:** Una búsqueda automática de imágenes puede devolver fotografías con branding incidental o con un contexto distinto al que comunica la tarjeta.

**How to apply:** Revisar visualmente cada asset local nuevo y preferir fotografías neutrales de procedimiento, persona o entorno clínico cuando todavía no existan imágenes propias.
