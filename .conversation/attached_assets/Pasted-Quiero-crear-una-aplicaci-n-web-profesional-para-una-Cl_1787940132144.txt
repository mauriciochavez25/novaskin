Frontend:
- React
- TypeScript
- JavaScript cuando sea necesario
- Vite
- Tailwind CSS
- Shadcn/UI
- React Query para manejo de datos

Backend:
- Node.js
- Express.js
- TypeScript
- API REST

Base de datos:
- PostgreSQL
- Drizzle ORM

Arquitectura:
- Separar claramente frontend y backend.

# RESPONSIVE DESIGN

La aplicación debe ser Mobile First.

Debe funcionar perfectamente en:

- iPhone 13 Pro Max
- iPhone 14
- iPhone 15
- Samsung Galaxy S24
- Tablets
- Laptops
- Pantallas de escritorio grandes

Requisitos:

- Menú responsive tipo hamburguesa en móviles.
- Botones grandes y fáciles de presionar.
- Imágenes adaptables.
- Videos responsivos.
- Texto legible en pantallas pequeñas.
- No debe existir scroll horizontal.

- Utilizar breakpoints de Tailwind.
- Probar específicamente resoluciones similares a iPhone 13 Pro Max y Samsung Galaxy S24.
